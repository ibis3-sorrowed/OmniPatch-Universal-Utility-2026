### Which specific AI applications and versions are supported?

OmniPatch supports the latest desktop versions of ChatGPT, Claude, Perplexity, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI Assistant as of the latest patch update.

### How often is OmniPatch updated for new app versions?

We aim to release compatibility updates within 72 hours of a major update to any supported application, with regular bi-weekly maintenance patches.

### Will using OmniPatch get my accounts banned?

OmniPatch modifies local application binaries, not server-side authentication. While we design it to minimize detection, account-related risks are inherent with any such tool.

### Can I use OmniPatch on a work computer with restricted permissions?

OmniPatch requires administrator privileges to modify application files in protected directories. It may not work on heavily restricted corporate devices without IT support.

### Does OmniPatch work on macOS or Linux systems?

No, OmniPatch is currently developed exclusively for Windows 10 and 11 desktop environments.

### What happens if a patched application receives an automatic update?

The patch may be overwritten by an official update. We recommend re-running OmniPatch after any significant application update to reapply the modifications.

### Is there a way to undo the patch and restore the original application?

Yes, OmniPatch includes a restore feature that can revert the targeted application files to their original state before patching.
